Guide d'utilisation de MyMiniMAL++

Découvrez toutes les fonctionnalités pour gérer votre collection

Fonctionnalités principales

Ajouter un élément

Cliquez sur le bouton "Ajouter" dans la barre de navigation. Remplissez les informations requises dans le formulaire qui s'ouvre.

Recherche automatique

Commencez à taper le titre, et le système vous suggérera automatiquement des mangas/animes avec leurs couvertures.

Gestion des chapitres

Utilisez les boutons + et - sur chaque carte pour mettre à jour votre progression rapidement.

Personnalisation

Mode sombre

Basculez entre les thèmes clair et sombre avec le bouton dans la barre de navigation.

Vue minimaliste

Activez la vue minimaliste pour un affichage plus compact de votre collection.

Gestion des catégories

Créez et gérez vos propres catégories pour organiser votre collection.

Statistiques et données

Visualisation des données

Accédez à des graphiques détaillés montrant la répartition de votre collection :

  • Distribution par catégorie
  • Statuts (En cours, Terminé, En pause)
  • Tags populaires
  • Progression globale
Astuce : Vous pouvez exporter vos données au format JSON pour les sauvegarder ou les transférer vers un autre appareil.

Raccourcis et astuces

Glisser-déposer

Réorganisez vos éléments en les faisant glisser à la position souhaitée.

Filtres et tri

Utilisez les options de filtrage et de tri pour organiser l'affichage de votre collection.

Tags et notes

Ajoutez des tags et des notes personnelles pour mieux organiser et retrouver vos contenus.

FAQ

Comment sauvegarder mes données ?

Utilisez le bouton d'export dans la barre de navigation pour télécharger vos données au format JSON.

Comment restaurer mes données ?

Cliquez sur le bouton d'import et sélectionnez votre fichier JSON précédemment exporté.

Les données sont-elles synchronisées ?

Oui, toutes vos données sont automatiquement synchronisées avec votre compte Supabase.

Note importante : Pensez à vous connecter pour profiter de la synchronisation de vos données entre appareils.
